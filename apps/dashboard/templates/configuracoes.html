ATUALIZAÇÃO DO SISTEMA

Aplicar a atualização?

O laboratório sincronizará o branch padrão do GitHub, atualizará as imagens e recriará os containers. O dashboard ficará indisponível por alguns instantes durante a aplicação.

Alterações e arquivos locais do Git serão guardados em backup e não serão mesclados com o GitHub. O arquivo .env e os dados dos volumes serão preservados. A operação exige conexão com o GitHub e pode baixar vários gigabytes.
