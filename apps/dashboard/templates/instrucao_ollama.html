Manual Avançado: Ollama

O Ollama é o coração do processamento cognitivo do laboratório da Seção Delta. Ele atua como o servidor responsável por extrair, carregar e executar Inferências sobre Modelos de Linguagem de Grande Porte (LLMs) puramente locais.

1. Introdução ao Motor

Ao contrário das APIs em nuvem (como OpenAI ou Anthropic), o Ollama foi concebido para rodar no metal da nossa máquina. Isso assegura Privacidade Total (Off-Grid), onde nenhum dado sigiloso de inteligência trafega pela internet.

  • Ele opera como um "Deamon" (Serviço de Fundo), recebendo requisições e retornando a geração de texto.
  • Não possui interface gráfica nativa. Operadores experientes o gerenciam inteiramente por Linha de Comando (CLI).
  • É capaz de operar dezenas de modelos abertos, de famílias como Llama (Meta), Qwen (Alibaba), Mistral e Gemma (Google).

2. Arquitetura e VRAM (Hardware)

Atenção ao Hardware: O limite da inteligência artificial local não é ditado apenas pelo Processador (CPU), mas sim pela VRAM (Memória de Vídeo da Placa Gráfica).

O Ollama faz a carga dos modelos (que são gigantescas matrizes de pesos neurais) diretamente na placa NVIDIA RTX 4060 do laboratório. Se o modelo for maior que a VRAM disponível, o Ollama faz um offload (transbordo) para a memória RAM comum e para a CPU, o que reduz drasticamente a velocidade de resposta.

Entendendo o Tamanho (Parâmetros) e Quantização

Quando pesquisamos modelos, sempre vemos números como 3B, 7B ou 70B. Isso refere-se à quantidade de "Bilhões de Parâmetros".

  • 7B a 8B: Ocupam cerca de 4 a 5 GB de VRAM. Excelentes para a nossa placa RTX 4060. Respondem instantaneamente.
  • 70B: Ocupam cerca de 40 GB de VRAM. São proibitivos para placas menores e forçam o processamento lento via CPU.
  • Quantização (ex: Q4_K_M): O Ollama automaticamente comprime os pesos matemáticos dos modelos para que caibam na memória sem perda notável de raciocínio lógico.

3. Gestão Básica de Modelos

Gerenciar os arquivos locais é fundamental. Você executa os comandos injetando ações no container Docker do Ollama.

Listar Modelos na Memória

Mostra tudo o que já está baixado e o tamanho real no disco.

Terminal (WSL)
docker exec -it ollama ollama list

Baixar Novos Modelos (Pull)

Baixa um modelo oficial do registro de modelos do Ollama. Arquivos grandes, requer boa internet temporariamente.

Terminal (WSL)
docker exec -it ollama ollama pull llama3.2 docker exec -it ollama ollama pull qwen2.5:7b-instruct docker exec -it ollama ollama pull nomic-embed-text

Apagar Modelos (RM)

Exclui definitivamente um modelo. Essencial para manter o SSD do laboratório limpo.

Terminal (WSL)
docker exec -it ollama ollama rm mistral

Ver Detalhes do Modelo (Show)

Inspeciona os metadados do modelo, como a licença, o template de prompt e os parâmetros ocultos.

Terminal (WSL)
docker exec -it ollama ollama show llama3.2 --modelfile

4. CLI Avançado e Interação

Você pode abrir um chat isolado apenas no texto (terminal) sem depender da rede ou de interfaces gráficas. É a forma mais direta de medir o tempo de resposta bruto.

Modo Interativo
docker exec -it ollama ollama run llama3.2

Ao entrar nesse modo, você verá um cursor >>>. Dicas de uso avançado:

  • Comandos internos: Digite /? para ver os comandos de atalho dentro do chat.
  • Multilinhas: Para enviar um texto que possui quebras de linha (um código enorme ou documento), envolva a mensagem com três aspas: """ Meu texto aqui """.
  • Sair: Digite /bye para encerrar o processo.

5. Compilação Customizada (Modelfile)

O Ollama permite compilar clones especializados de modelos base. Se você não quer repetir "Haja como um especialista" a cada prompt, você injeta isso diretamente no DNA de um novo modelo usando um Modelfile.

Criando o Arquivo Modelfile

No seu terminal, crie um arquivo chamado Modelfile com o seguinte conteúdo:

Arquivo: Modelfile
FROM llama3.2 # 1. Comportamento Base (Cérebro do Agente) SYSTEM """Você é um analista de inteligência. Apenas responda em tópicos curtos. Não use jargões motivacionais.""" # 2. Parâmetros de Geração (Matemática Pura) PARAMETER temperature 0.2 # Quanto menor, menos "criativo/alucinado" e mais determinístico PARAMETER num_ctx 8192 # Aumenta a memória da conversa para 8 mil tokens PARAMETER top_k 40 # Restringe as escolhas lógicas PARAMETER repeat_penalty 1.15 # Punição por repetição # 3. Exemplo de Injeção de Histórico MESSAGE user "Relatório inicial:" MESSAGE assistant "Aguardando ordens de extração, Senhor."

Compilando o Modelo Customizado

Para construir a sua versão, copie o arquivo para dentro do container e ordene a compilação:

Terminal (WSL)
docker cp Modelfile ollama:/Modelfile docker exec -it ollama ollama create AnalistaMilitar -f /Modelfile

Imediatamente após rodar, o modelo AnalistaMilitar aparecerá no seu comando ollama list e poderá ser selecionado no n8n ou no Open WebUI!

6. Consumo via API REST HTTP

Sistemas corporativos não interagem com o Ollama digitando comandos no terminal. Eles usam Programação e Redes. O Ollama expõe um servidor Web (HTTP) na porta 11434.

Qualquer linguagem de programação (Python, Javascript, Rust) pode enviar uma requisição HTTP POST para o Ollama e receber a resposta em JSON.

Exemplo de Integração Bruta (cURL)

Para comprovar isso, execute este comando no terminal para fazer uma chamada de rede direta ao cérebro de IA:

Requisição HTTP (POST)
curl -X POST http://localhost:11434/api/generate -d '{ "model": "llama3.2", "prompt": "Explique o conceito de latência de rede em uma frase.", "stream": false }'

Essa é exatamente a mesma comunicação invisível que ferramentas como o n8n e o LiteLLM fazem por trás das cortinas.
