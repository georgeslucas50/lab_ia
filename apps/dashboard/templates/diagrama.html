Exemplos de fluxos de estudo

📓Explorar um modelo no notebook
JupyterLab → LiteLLM → Ollama

O aluno escreve Python no JupyterLab e usa a API OpenAI compatível do gateway, ou acessa o Ollama diretamente para experimentar seus endpoints.

📚Montar uma busca RAG
Arquivo → Tika → embeddings → Qdrant

Um fluxo configurado extrai o texto, gera embeddings com o modelo escolhido, indexa os vetores e recupera trechos para compor o contexto enviado ao LLM. Tika e Qdrant são opcionais.

⚡Automatizar uma tarefa com agente
n8n / Flowise → LiteLLM → MCP / dados

O orquestrador encadeia etapas, chama o modelo e, quando o fluxo está configurado, usa ferramentas expostas pelo servidor MCP ou por bancos do laboratório.

🎙️Experimentar entrada e saída por voz
Áudio → Whisper → LLM → OpenEDAI Speech

O serviço de transcrição converte fala em texto e o serviço TTS transforma a resposta em áudio. Ambos são opcionais e usam CPU na configuração padrão.

⌁ Rede interna

Os containers se encontram pela rede Docker ai_network, usando o nome do serviço como endereço, por exemplo http://ollama:11434.

⌂ Acesso local

As portas publicadas no host estão vinculadas a 127.0.0.1. Em geral, o aluno abre as ferramentas no próprio navegador em endereços localhost.

▤ Dados persistentes

Volumes nomeados guardam modelos, bancos e arquivos de trabalho fora do ciclo de vida do container. Recriar um container, por si só, não apaga esses dados.
