⚡ Introdução ao n8n

O n8n é o cérebro orquestrador do nosso Laboratório. Ele é uma ferramenta visual avançada que permite criar automações complexas e agentes de inteligência artificial ligando blocos lógicos uns aos outros, sem escrever código.

  • No-Code / Low-Code: Você não precisa programar. Tudo é feito arrastando e conectando blocos lógicos na tela.
  • Gatilhos (Triggers): Todo fluxo começa com um gatilho. Pode ser o recebimento de um e-mail, uma chamada de webhook, um formulário preenchido ou até mesmo um agendamento de hora em hora.
  • Integração Ampla: Ele se conecta nativamente aos nossos modelos de IA locais (LiteLLM/Ollama), bancos de dados (Postgres, Qdrant) e milhares de ferramentas externas (Tika, Scraping, APIs do exército).

🧩 Como funcionam os Nodes (Nós)

Um fluxo (workflow) de trabalho é inteiramente composto por vários Nodes. Cada Node executa uma ação ou processamento específico e isolado.

  1. Ao abrir o painel do n8n, você verá uma tela em branco chamada canvas.
  2. Clicando no sinal de +, você adiciona novos Nodes de acordo com a função desejada.
  3. Você liga a saída (o círculo à direita) de um Node à entrada (círculo à esquerda) do próximo Node.
  4. Os dados (geralmente estruturados em JSON) fluem através dessa linha, sendo processados etapa por etapa, de maneira muito similar a uma linha de montagem de fábrica.

🤖 Conectando a Inteligência Artificial

No laboratório, nossos LLMs (Modelos de Linguagem de Grande Porte) rodam localmente e 100% privados na GPU via Ollama, protegidos e roteados pelo Gateway LiteLLM.

Para embutir capacidades de Inteligência Artificial dentro do seu workflow no n8n, você deve seguir estes passos fundamentais:

  • No canvas, adicione um Node chamado "Basic LLM Chain" ou "AI Agent", que ficam na aba de Advanced AI.
  • Conecte a ele um Node de Modelo de Linguagem (ex: Chat OpenAI).
  • Na configuração do modelo, selecione a credencial pré-configurada que aponta para o nosso LiteLLM local (ex: http://litellm:4000/v1).
  • No campo de Prompt, defina as instruções claras do que a IA deve analisar. Quando o fluxo de execução chegar ali, a IA processará o texto, analisará a requisição e devolverá o resultado estruturado para o próximo Node.

🎯 O Primeiro Exercício Prático

A teoria só ganha sentido na prática. Quando você iniciar a Área de Projetos, o seu primeiro desafio será criar uma interface de comunicação máquina-a-máquina.

Seu objetivo será criar um fluxo que é acionado via Webhook. Ele deve operar da seguinte forma:

  • O fluxo fica escutando uma porta de rede aguardando chamadas.
  • O webhook receberá uma requisição POST contendo um JSON. Exemplo: {"pergunta": "Qual a capital do Brasil?"}.
  • Esse JSON é passado para um Node de Inteligência Artificial, que fará a compreensão da pergunta.
  • O fluxo processará a saída da IA e devolverá a resposta final estruturada (HTTP 200 OK) de volta para o cliente que chamou o Webhook.
